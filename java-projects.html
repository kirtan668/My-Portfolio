LibraTrack — Library Management System

GitHub repo ↗ Download .java ↓

A library system with separate admin and student logins. Admins manage the book catalog and track copies in stock; students can search, request, and return books. Issue dates, due dates, and per-day fines are calculated automatically. The full version persists everything to MySQL through JDBC and uses a Swing interface — the downloadable file below is a self-contained console demo of the same core logic.

  • Book catalog with per-title copy tracking
  • Issue / return workflow with due dates
  • Automatic per-day fine calculation
  • Admin vs. student account separation
OOP Design JDBC · MySQL Swing GUI java.time

import java.time.LocalDate;
import java.time.temporal.ChronoUnit;
import java.util.*;

public class LibraTrack {

    static final int LOAN_DAYS = 14;
    static final double FINE_PER_DAY = 5.0;

    static class Book {
        String isbn, title, author;
        int totalCopies, availableCopies;

        Book(String isbn, String title, String author, int copies) {
            this.isbn = isbn;
            this.title = title;
            this.author = author;
            this.totalCopies = copies;
            this.availableCopies = copies;
        }
    }

    static class Loan {
        String isbn, memberId;
        LocalDate issueDate, dueDate;
        boolean returned = false;

        Loan(String isbn, String memberId) {
            this.isbn = isbn;
            this.memberId = memberId;
            this.issueDate = LocalDate.now();
            this.dueDate = issueDate.plusDays(LOAN_DAYS);
        }
    }

    static void returnBook(Member m, String isbn, Map<String, Book> catalog) {
        for (Loan l : m.loans) {
            if (l.isbn.equals(isbn) && !l.returned) {
                l.returned = true;
                catalog.get(isbn).availableCopies++;
                long lateDays = Math.max(0, ChronoUnit.DAYS.between(l.dueDate, LocalDate.now()));
                double fine = lateDays * FINE_PER_DAY;
                System.out.println(fine > 0 ? "Fine due: Rs " + fine : "No fine — on time.");
                return;
            }
        }
    }

    // Full menu-driven main(), seed data, issue/return/view-fines
    // handlers are in the downloadable file above.
}

MediQueue — Hospital Appointment System

GitHub repo ↗ Download .java ↓

An appointment and scheduling system for a small clinic. Patients book slots against doctor availability, doctors can pull their own day's queue, and admins manage schedules and records. Role-based access keeps each user type limited to their own view, with all data backed by a relational schema in the full JDBC/MySQL build — the downloadable file is a console demo of the booking logic.

  • Per-doctor open-slot scheduling
  • Patient booking against real-time availability
  • Doctor-facing daily queue view
  • Role-based access for admin / doctor / patient
Role-Based Access JDBC · MySQL Scheduling Logic Streams API

MediQueue.java

console demo · runnable 
public class MediQueue {

    static class Doctor {
        String id, name, specialization;
        List<String> slots = new ArrayList<>();
    }

    static class Appointment {
        Patient patient;
        Doctor doctor;
        String slot;
    }

    static void bookAppointment(Patient p, Doctor d, String slot,
                                 List<Appointment> appointments) {
        if (!d.slots.remove(slot)) {
            System.out.println("That slot isn't available.");
            return;
        }
        appointments.add(new Appointment(p, d, slot));
        System.out.println("Booked: " + slot + " with Dr. " + d.name);
    }

    static void viewDoctorQueue(Doctor d, List<Appointment> appointments) {
        appointments.stream()
            .filter(a -> a.doctor.id.equals(d.id))
            .sorted(Comparator.comparing(a -> a.slot))
            .forEach(a -> System.out.println(a.slot + " — " + a.patient.name));
    }

    // are in the downloadable file above.
}

StockLedger — Inventory & Billing System

GitHub repo ↗ Download .java ↓

A console-based inventory and billing tool for a small shop. It tracks stock levels with low-stock alerts, builds itemized invoices at the point of sale, and appends a daily sales report to disk. Built purely with core Java collections and file I/O — no external database — so it stays lightweight and runs anywhere with just a JDK.

  • Live stock tracking with reorder-level alerts
  • Multi-item invoice generation at time of sale
  • Daily sales report appended to a text file
  • No external dependencies — pure core Java

public class StockLedger {

    static class Product {
        String sku, name;
        double price;
        int quantity, reorderLevel;
    }

    static void appendDailyReport(int invoiceId, List<String> lines, double total) {
        try (FileWriter fw = new FileWriter("sales_report.txt", true)) {
            fw.write("Invoice #" + invoiceId + " — " + LocalDate.now() + "\n");
            for (String line : lines) fw.write("  " + line + "\n");
            fw.write(String.format("  TOTAL: Rs %.2f%n%n", total));
        } catch (IOException e) {
            System.out.println("Could not write report: " + e.getMessage());
        }
    }
